# clampnode

Clamp validation gates for node inputs before they hit prod.

**Site:** https://theworker02.github.io/clampnode/

## Install / run

```bash
git clone https://github.com/theworker02/clampnode.git
cd clampnode
node src/cli.js
node --test
```
